# gym-plan

A 3-day aesthetic (V-taper) workout plan website: Monday Push, Wednesday Pull + Abs, Friday Legs + Shoulders.

Live site (once GitHub Pages is enabled on `main`): https://zharfycode.github.io/gym-plan/

Features: exercise checklist with progress bar, per-exercise weight log (saved in your browser), rest timer, warm-up/progression/nutrition notes, mobile and dark-mode friendly.
